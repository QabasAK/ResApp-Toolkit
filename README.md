# Research Applications Toolkit

A LaTeX toolkit for research applications with CV, SoP, and LoR templates built for Overleaf, with a cold email guide and step-by-step wiki. Made for undergraduates navigating their first research applications. The wiki has everything: guides, tips, and a cold email template. Check it out!
